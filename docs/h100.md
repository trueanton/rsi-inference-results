# H100 baseline qualification

Qwen3.6-27B served BF16 on one H100 at TP=1. GPT-OSS-120B served MXFP4 on two H100s at TP=2. Both public correctness checks passed, and every timed request completed in both unchanged-engine arms. The original verifier classified each tree as empty and returned `no_patch`. The campaign ran zero solver attempts.

TTFT is median time to first token. TPOT is median time per output token after the first. Prefill returns one token per request. Total throughput includes input and output tokens.

Each arm measured four 1,024-in/8,192-out requests per decode boot, five repetitions of 256 8,192-in/1-out requests for prefill, and 256 1,024-in/1,024-out requests per high-load profile and repetition. Qwen used one decode boot and one high-load repetition. GPT used two decode boots and two high-load repetitions. The table excludes warmups. It averages per-run statistics, dropping the lowest and highest values in the five-run prefill series. The harness separately computes the decode and prefill scores from reciprocal median latencies, and combines high-load request rates by geometric mean across the three profiles.

## Interpreting the paired results

| Unchanged first arm / pristine arm | Decode | Prefill | High load | Overall |
| --- | ---: | ---: | ---: | ---: |
| Qwen3.6-27B | 0.982468× | 0.996439× | 1.001517× | 0.993442× |
| GPT-OSS-120B | 1.082275× | 1.010081× | 1.001347× | 1.030606× |

The GPT first arm measured 216.16 and 216.13 output tokens/s in its two decode boots. The pristine arm averaged 199.61 output tokens/s. Both used the same devices and seed, NCCL 2.27.5, FlashAttention 3 and the Triton MXFP4 backend. Each arm used its own compilation cache. The 8.23% decode difference persisted across boots and its cause remains unresolved. All ratios above describe controls. An optimization speedup was unmeasured.

## Setup and evidence

Both jobs used Apptainer 1.4.5 and the original workload definitions. Qwen used three CUDA 12 package overrides to satisfy the installed Torch wheel. GPT matched all 191 original pins and used a checksum-verified offline Harmony vocabulary. For hardware comparisons, Qwen used one H100 at TP=1 and two A100s at TP=2 in the diagnostic. GPT used TP=2 on both systems, with distinct checkpoint revisions, serving memory settings and kernel backends.
